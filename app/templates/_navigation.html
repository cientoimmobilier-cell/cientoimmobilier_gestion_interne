{# Macros de navigation homogènes pour toute l'application (DRY / SOLID). Comportement du bouton Retour : 1. Si une URL `next` (filtres + pagination conservés) est fournie -> on y va. 2. Sinon, si l'historique du navigateur existe -> history.back(). 3. Sinon -> URL de repli de la liste principale du module (`back_url`). Fonctionne aussi bien sous Flask que sous PyWebView/Desktop. #} {% macro render_back_button(fallback_url='', label='Retour', next_url='') %} {% endmacro %} {% macro render_breadcrumb(items, current_title) %}
  1. Accueil
    2. {% for label, url in items %}
  2. {{ label }}
    3. {% endfor %}
  3. {{ current_title }}
{% endmacro %} {# Bandeau de navigation standard à placer en haut de chaque page : bouton Retour à gauche, fil d'Ariane à droite. Paramètres : current_title : titre de la page courante (dernier élément du fil d'Ariane). breadcrumb_items : liste de tuples (libellé, url) précédant la page courante. back_url : URL de repli du bouton Retour (liste du module) si aucun historique. back_label : libellé du bouton Retour (défaut 'Retour'). next_url : URL conservant filtres/pagination (via le paramètre ?next=). #} {% macro page_navigation(current_title, breadcrumb_items=[], back_url='', back_label='Retour', next_url='') %}
{{ render_back_button(back_url, back_label, next_url) }} {{ render_breadcrumb(breadcrumb_items, current_title) }}
{% endmacro %}
